# 航空温控货物运输放行与温度偏差调查平台

基于React、Ant Design、Zustand、React Router、TanStack Query、Axios、Vite和TypeScript的独立前端工程。无需后端，浏览器持久化演示数据。

## 功能

- 温控运输任务列表、关键词和状态筛选。
- **温控箱交接链**：中转换箱只切箱号，交接时刻前的旧箱温度点/证据冻结只读，新箱自交接时刻续记；跨交接温度偏差按责任时段拆成旧箱段（冻结保留历史）与新箱段（续记调查）。
- **备用箱容量**：备用箱池容量不足时交接排队并标缺口，缺口调拨补齐后同一笔交接生效；排队缺口未补齐拦截放行。
- **交接版本（乐观锁）**：两人同时提交交接确认时，后到者看到版本冲突且填写内容保留，可基于最新版本重试；落盘失败时整笔事务停留在交接前，可原样重试。各页统一显示 `handoverVersion`。
- 航段时间轴、温度曲线缩放、交接分界线、按箱号/冻结标记着色、原始时间点定位与超限标记。
- 温度曲线、设备报告、包装确认和交接签字证据随箱归属与版本管理。
- 温度超限自动/人工偏差、原因调查、影响评估和放行复核。
- 多角色签收、未核验证据、排队缺口与未关闭偏差放行拦截、完整报告导出。

端口为`18465`。

```bash
npm install
npm run build
npm run dev
```
